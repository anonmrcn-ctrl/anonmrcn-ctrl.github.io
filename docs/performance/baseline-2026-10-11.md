## Interventi

- gli script a fondo pagina conservano l'ordine ma non bloccano il parser;
- le pagine dinamiche anticipano soltanto la connessione al Worker;
- Memorie carica Leaflet, Esri e le tessere soltanto dopo un'azione esplicita;
- il CSS Leaflet è locale e le immagini critiche dichiarano dimensioni;
- l'indice Voci è un ripiego HTML sincronizzato dal generatore D1 e non viene
  ridisegnato quando l'elenco non cambia;
- il codice completo dell'editor Voci viene caricato solo per ricerca, URL con
  frammento o sessione amministrativa;
- il server di audit usa gzip e la stessa origine locale già autorizzata dal
  Worker, senza registrare richieste o dati personali.

## Campo e monitoraggio

TBT è un segnale di laboratorio e non sostituisce INP. L'INP al 75º
percentile verrà registrato da Search Console/CrUX quando esisterà un campione
sufficiente; fino ad allora rimane esplicitamente “in attesa di campione”. Non
viene aggiunta telemetria individuale per produrlo. Ogni pull request che tocca
HTML, CSS, JavaScript o immagini riesegue la matrice; un aumento oltre soglia
blocca il controllo e richiede causa, intervento e nuova misura.

Per ripetere i controlli statici dalla radice:

```bash
node scripts/check-performance.mjs
node scripts/check-content-boundary.mjs
node scripts/check-seo.mjs
node --test scripts/performance-loading.test.mjs scripts/public-pages.test.mjs worker/tests/*.test.mjs
```

La verifica su `main` e sulle risposte pubbliche viene registrata separatamente
dopo l'integrazione, così una misura di pull request non viene confusa con una
prova del sito in produzione.
