# Rapporti organici

Questa cartella contiene soltanto rapporti trimestrali aggregati che superano
`node scripts/check-organic-report.mjs`. Non inserire esportazioni grezze di
Search Console, query, URL singoli, dati personali, token o parametri QR.

La proprietà è verificata e la prima finestra osservata va dal 12 ottobre
all'8 novembre 2026. Il primo file `AAAA-QN.json` può essere aggiunto dal 9
novembre, soltanto dopo l'esportazione di una baseline reale; l'assenza prima
di tale data è intenzionale e non va sostituita con valori stimati. I rapporti
sono manutenzione operativa ricorrente, non una dipendenza dello sviluppo.
